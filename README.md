# 💘 520 专属表白网页

一份特别的爱意表达，只为你最爱的人准备

## 💕 项目简介

这是一个专为 520 情人节打造的互动表白网页，用代码传递你的心意。

## ✨ 功能特点

- **浪漫设计** - 粉色渐变背景，温馨浪漫的视觉体验
- **互动体验** - 点击、滑动等交互效果，增加趣味性
- **一键部署** - 支持 Gitee Pages 快速部署
- **自定义内容** - 轻松修改文案和图片，打造专属表白

## 🚀 快速开始

```bash
# 克隆仓库
git clone https://gitee.com/gitee_hyq/cloud.git

# 进入目录
cd cloud

# 启动本地服务器
python3 -m http.server 8080

# 打开浏览器访问
open http://localhost:8080
```

## 📝 自定义指南

### 修改表白文案
编辑 `index.html` 文件，找到以下内容修改：

```html
<h1>亲爱的，我想对你说...</h1>
<p>这里是你的表白内容...</p>
```

### 修改图片
将你的照片替换到 `images/` 目录下，文件名保持一致即可。

## 📱 响应式设计
