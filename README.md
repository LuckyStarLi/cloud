# 💝 AI 婚姻匹配系统

基于大模型语义理解的极简婚恋匹配平台

## 🌟 项目特点

- **极简设计** - 单一网页，无需APP/小程序
- **AI 智能匹配** - 利用大模型进行语义级精准匹配
- **三步完成** - 注册 → 匹配 → 双向确认
- **隐私保护** - 无聊天功能，省去内容审核

## 🚀 快速开始

```bash
# 克隆仓库
git clone https://gitee.com/gitee_hyq/cloud.git

# 进入目录
cd cloud

# 启动本地服务器
python3 -m http.server 8080

# 打开浏览器访问
open http://localhost:8080
```

## 📋 功能流程

1. **注册页** - 用户填写基本信息、自我介绍、择偶偏好（自由文本表达）
2. **匹配结果页** - 系统展示推荐对象及匹配度/匹配理由
3. **双向确认** - 双方确认后交换联系方式，流程结束

## 🛠️ 技术栈

- **前端**: HTML5 + CSS3 + JavaScript
- **后端**: 后期可扩展接入大模型 API（GPT-4、Claude、GLM-4 等）
- **部署**: Gitee Pages

## 📱 响应式设计

支持桌面端和移动端访问，适配各种屏幕尺寸。
